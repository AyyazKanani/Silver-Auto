## Silver Auto — Vehicle Service Management System

Silver Auto is a full-stack web application built with Django to streamline 
vehicle service center operations. It supports multiple user roles — Admin, 
Mechanic, Driver, and Customer — each with their own dashboard and permissions.

### Key Features
- Role-based authentication and dashboards (Admin / Mechanic / Driver / Customer)
- Vehicle and customer management
- Service request handling and mechanic assignment
- Inventory tracking for parts and supplies
- Driver attendance tracking
- Salary payment records for mechanics
- Built with 19+ interconnected Django models

### Tech Stack
- Backend: Python, Django
- Database: SQLite (default, can be swapped for PostgreSQL/MySQL)
- Frontend: Django Templates, HTML/CSS
